## 📖 About the Game

**Onimusha: Way of the Sword** is the first new entry in the legendary Onimusha series in over 20 years, developed and published by **CAPCOM**. The game was originally scheduled for September 25, 2026, but CAPCOM moved the release forward to **September 4, 2026**.

You play as legendary swordsman **Miyamoto Musashi**, who discovers a mystical Oni Gauntlet fused to his arm. In Edo-era Kyoto, twisted by malevolent clouds of Malice, you must fight against the demonic Genma invasion. The game is a **character action game**, not a Soulslike — focus on mastering Musashi's blade, parrying with the Issen system, and using the environment to your advantage.

**Key Game Features**:
- 🗡️ Exhilarating swordplay action with the Issen parry system
- 🎮 Character action game — not a Soulslike, no resource loss on death
- 🌆 "Open-town" hub in Kyoto with side paths, secrets, and NPCs
- ⚔️ Challenging boss fights with two difficulty levels
- 🎭 Miyamoto Musashi modeled on the iconic Toshiro Mifune
